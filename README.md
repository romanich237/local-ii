# Local AI Server

Самостоятельно размещаемый OpenAI-совместимый API на базе Ollama. Версия: **1.4.4**.

## Рекомендованный провайдер

Для размещения Local AI Server можно использовать хостинг [Play2Go](https://play2go.cloud/?ref_id=k5jH0xQ4-_g): доступны виртуальные и выделенные серверы, а также игровые серверы. Для нашего проекта выбирайте VPS/VDS с Ubuntu и ресурсами, соответствующими размеру используемых моделей.

## Установка

Требуется Linux с systemd, домен с A-записью на IP сервера и открытые TCP-порты **80/443**. Для установки нужен root-доступ.

```bash
sudo -i
cd /root
git clone https://github.com/romanich237/local-ii.git
cd /root/local-ii
bash install.sh
```

Установщик запросит домен, email для Let's Encrypt, логин администратора, основную модель и предложит подключить Telegram-бота. Telegram необязателен — ответьте `N`, чтобы пропустить его. В конце установки будет показан пароль администратора: сохраните его.

| Раздел | Адрес |
|---|---|
| Админ-панель | `https://ВАШ-ДОМЕН/auth/` |
| Документация | `https://ВАШ-ДОМЕН/docs` |
| API | `https://ВАШ-ДОМЕН/v1` |
| Состояние | `https://ВАШ-ДОМЕН/health` |
| Поддержка | [Telegram](https://cyxap.top/tg) |

## Telegram Mini App и настройки бота

В разделе **Настройки Telegram** админ-панели можно включить или отключить бота, задать Telegram Bot Token и числовой ID администратора. Mini App использует Telegram WebApp API: отправляет исходный `initData` на сервер, сервер проверяет HMAC-подпись и срок действия, затем сверяет подписанный `user.id` с `adminUserId` и выдаёт сессию админ-панели. Значение ID из браузера без проверки подписи не используется. Токен хранится в локальном `config.json` с ограниченными правами доступа; при сохранении перезапускается только процесс бота.

Команда `/start` показывает кнопку открытия Telegram Mini App. Mini App содержит быстрые переходы к обзору сервера, моделям, чату, настройкам и новостям. Для полноценной авторизации в веб-панели используется отдельная учётная запись администратора.

| Команда | Действие |
|---|---|
| `/panel` | Открыть Mini App |
| `/models` | Список установленных моделей |
| `/stats` | Статистика запросов и токенов за месяц |

После пяти неудачных попыток входа с одного IP адрес блокируется на 15 минут, а администратору отправляется уведомление в Telegram с IP-адресом и временем события. Для автоматической рассылки бот должен быть включён, а администратор должен хотя бы один раз начать с ним личный чат. Сервер самостоятельно проверяет публичную ленту канала @localiirom каждые 3 минуты и отправляет новые публикации в Telegram; отдельная команда для получения новостей не нужна. При первом запуске фиксируется последняя публикация, чтобы не рассылать старую историю.


Mini App поддерживает резервный вход по логину и паролю администратора. Если Telegram не передал подписанный `initData` или подписанный Telegram ID не совпадает с настроенным ID администратора, отображается форма входа с теми же учётными данными, что используются в веб-админке. Сервер применяет общий лимит неудачных попыток и создаёт обычную защищённую сессию. Неподписанный `initDataUnsafe.user.id` не используется для авторизации.

### Если Mini App сообщает, что Telegram не передал initData

Открывайте приложение из личного чата с ботом через кнопку Web App в сообщении `/start` или через кнопку меню бота. Обычное открытие URL в браузере не передаёт подписанные данные Telegram. Проверьте, что в настройках бота задан корректный HTTPS-домен и URL Mini App доступен с этого домена. Внутри приложения предусмотрено ожидание загрузки WebApp API и повторная проверка. Для безопасности сервер никогда не авторизует пользователя только по `initDataUnsafe.user.id`.

## Каталог моделей Ollama

В разделе **Модели → Полный каталог** доступен поиск по моделям из [официальной библиотеки Ollama](https://ollama.com/library). Список загружается с сайта Ollama при открытии вкладки и кэшируется браузером на время текущего сеанса. Доступность и теги моделей могут изменяться на стороне Ollama; перед установкой проверяйте страницу модели. Для загрузки используется команда Ollama `pull`.

## Модели

## Подключение к API

Создайте ключ в панели и передавайте его в заголовке `Authorization: Bearer`.

```bash
curl https://ВАШ-ДОМЕН/v1/chat/completions \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3:8b",
    "messages": [
      {"role": "system", "content": "Отвечай по-русски."},
      {"role": "user", "content": "Привет!"}
    ]
  }'
```

Список установленных моделей: `GET /v1/models`. Если `model` не указан, используется модель по умолчанию.

### Контекст диалога

API не хранит историю между запросами. Клиент должен передавать её в `messages` при каждом обращении, включая предыдущие ответы ассистента и сообщения пользователя в правильном порядке.

| Роль | Назначение |
|---|---|
| `system` | Системные инструкции |
| `user` | Сообщение пользователя |
| `assistant` | Предыдущий ответ модели |

Встроенный чат панели автоматически отправляет до 40 последних реплик. История действует в пределах открытой страницы; перезагрузка или очистка чата сбрасывает её.

### Python / OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://ВАШ-ДОМЕН/v1",
    api_key="ВАШ_API_КЛЮЧ"
)

response = client.chat.completions.create(
    model="qwen3:8b",
    messages=[{"role": "user", "content": "Привет!"}],
    max_tokens=1024
)
print(response.choices[0].message.content)
```

Официальный сайт ChatGPT не позволяет заменить API Base URL на локальный сервер. Для этого используйте OpenAI SDK или совместимые интерфейсы, например LibreChat и Open WebUI.

## Сброс пароля администратора

Если забыли пароль от веб-панели, выполните на сервере от имени пользователя, которому принадлежит PM2 (обычно root):

```bash
cd /root/local-ii
npm run reset-password
```

Скрипт создаст новый случайный пароль, безопасно обновит его хэш в `config.json`, сменит секрет подписи сессий и перезапустит `local-ai-api`. Все ранее открытые сессии админ-панели станут недействительными. Новый пароль будет показан в терминале один раз — сразу сохраните его. API-ключи и их шифрование не затрагиваются.

Если PM2 не удалось перезапустить автоматически, выполните:

```bash
pm2 restart local-ai-api --update-env
```

## Обновление

Автообновление проверяет ветку `main`. В панели доступна ручная проверка обновлений.

Для ручного обновления войдите под пользователем, от которого запущен PM2 (по умолчанию root):

```bash
cd /root/local-ii
git fetch --prune origin main
git merge --ff-only origin/main
if [ -f package-lock.json ]; then
  npm ci --omit=dev
else
  npm install --omit=dev --no-package-lock
fi
pm2 startOrReload ecosystem.config.cjs --update-env
pm2 save
```

Проверка состояния:

```bash
pm2 status
pm2 logs local-ai-updater --lines 100
curl -fsS "http://127.0.0.1:$(node -p "require('./config.json').port")/health"
```

## Новости проекта

Админ-панель получает публикации из [официального Telegram-канала](https://t.me/localiirom). Лента проверяется автоматически примерно каждые 3 минуты; в панели список обновляется раз в минуту.

Если Telegram-бот включён и настроен, о каждой новой публикации приходит личное уведомление администратору. При первом запуске сервис загружает последние публикации в панель без отправки старых уведомлений. Для получения уведомлений бот должен быть запущен, а администратор должен хотя бы один раз открыть с ним личный чат и нажать Start.

Новости автоматически рассылаются ботом после обнаружения новой публикации. Команды `/news` нет. Без настроенного Telegram-бота новости остаются доступны в админ-панели.

## Безопасность и резервные копии

- Не открывайте порт Ollama `11434` напрямую в интернет.
- Не публикуйте `config.json`, SQLite-базу, пароли и API-ключи.
- Новые ключи проверяются по SHA-256-хэшу; зашифрованное значение доступно администратору для просмотра.
- Сохраняйте резервные копии `config.json` и `data/local-ai.db`.
- Не теряйте `sessionSecret`: от него зависит шифрование сохранённых ключей.
