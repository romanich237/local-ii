# Local AI Server

Самостоятельно размещаемый OpenAI-совместимый API на базе Ollama. Версия: **1.3.3**.

## Установка

Требуется Linux с systemd, публичный домен с A-записью на IP сервера и открытые TCP-порты **80/443**. Для установки нужен root-доступ.

Репозиторий публичный — GitHub PAT не требуется.

```bash
sudo -i
cd /root
git clone https://github.com/romanich237/local-ii.git
cd /root/local-ii
bash install.sh
```

Установщик запросит домен, email для Let's Encrypt, логин администратора, основную модель и предложит подключить Telegram-бота. Telegram необязателен — ответьте `N`, чтобы пропустить его. В конце установки будет показан пароль администратора: сохраните его.

После установки:

| Раздел | Адрес |
|---|---|
| Админ-панель | `https://ВАШ-ДОМЕН/auth/` |
| Документация | `https://ВАШ-ДОМЕН/docs` |
| API | `https://ВАШ-ДОМЕН/v1` |
| Проверка состояния | `https://ВАШ-ДОМЕН/health` |
| Поддержка | [Telegram](https://cyxap.top/tg) |

## Требования

| Параметр | Рекомендация |
|---|---|
| ОС | Ubuntu/Debian или другая поддерживаемая systemd-система |
| Архитектура | x86_64 или ARM64 |
| RAM | от 4 ГБ для компактных моделей; 8–16 ГБ и более для моделей 7B+ |
| Диск | от 10 ГБ плюс место под модели |
| Сеть | домен, TCP 80 и 443 |
| GPU | необязателен; NVIDIA ускоряет генерацию при наличии совместимого драйвера |

Установщик поддерживает APT, DNF/YUM, Pacman и Zypper. Для Alpine и систем без systemd потребуется ручная адаптация.

## Модели

Управление моделями находится в админ-панели: **Модели → `/auth/models`**.

Каталог Ollama: [ollama.com/library](https://ollama.com/library).

Примеры команд:

```bash
ollama pull qwen3:8b
ollama list
ollama rm qwen3:8b
```

Доступная модель и её точный тег зависят от установленной Ollama и ресурсов сервера.

## Подключение к API

Создайте ключ в админ-панели. Для запросов используйте заголовок `Authorization: Bearer`.

### Chat Completions

```bash
curl https://ВАШ-ДОМЕН/v1/chat/completions \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3:8b",
    "messages": [
      {"role": "system", "content": "Отвечай по-русски."},
      {"role": "user", "content": "Привет!"}
    ]
  }'
```

Если `model` не указан, используется модель по умолчанию. Список установленных моделей доступен через `GET /v1/models`.

### Контекст диалога

API не хранит контекст между запросами. Клиент должен сам передавать историю в `messages` при каждом обращении: системную инструкцию, сообщения пользователя и предыдущие ответы ассистента — в правильном порядке.

| Роль | Назначение |
|---|---|
| `system` | Системные правила и контекст |
| `user` | Сообщение пользователя |
| `assistant` | Предыдущий ответ модели |

Встроенный чат админ-панели автоматически передаёт до 40 последних реплик. История хранится в открытой странице браузера; перезагрузка или кнопка «Очистить чат» сбрасывает её. В собственном приложении храните историю на стороне клиента и учитывайте контекстное окно модели.

### Python / OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://ВАШ-ДОМЕН/v1",
    api_key="ВАШ_API_КЛЮЧ"
)

response = client.chat.completions.create(
    model="qwen3:8b",
    messages=[
        {"role": "user", "content": "Привет!"}
    ],
    max_tokens=1024
)
print(response.choices[0].message.content)
```

Официальный сайт ChatGPT не позволяет заменить сервер OpenAI произвольным Base URL. Используйте OpenAI SDK или совместимые интерфейсы, например LibreChat и Open WebUI.

## Telegram

Telegram-бот необязателен. При включении укажите токен от [@BotFather](https://t.me/BotFather) и числовой Telegram user ID администратора. Проверяется ID отправителя; посторонние аккаунты не получают доступ.

| Команда | Действие |
|---|---|
| `/keys` | Список API-ключей |
| `/newkey имя [лимит]` | Создать ключ |
| `/reveal ID` | Показать ключ |
| `/on ID`, `/off ID` | Включить / отключить ключ |
| `/delete ID` | Удалить ключ |
| `/chat`, `/stop` | Начать / завершить чат |
| `/clear` | Очистить историю чата |
| `/model тег` | Выбрать модель |
| `/system текст` | Задать системный промт |
| `/max число` | Лимит выходных токенов |
| `/status` | Состояние Ollama |

## Обновление

Автообновление проверяет публичную ветку `main` без личного GitHub PAT. В админ-панели доступна кнопка проверки обновлений.

Ручное обновление выполняйте от имени пользователя, под которым запущен PM2 (стандартно — root):

```bash
cd /root/local-ii
git fetch --prune origin main
git merge --ff-only origin/main
if [ -f package-lock.json ]; then
  npm ci --omit=dev
else
  npm install --omit=dev --no-package-lock
fi
pm2 startOrReload ecosystem.config.cjs --update-env
pm2 save
```

Проверка:

```bash
pm2 status
pm2 logs local-ai-updater --lines 100
curl -fsS "http://127.0.0.1:$(node -p "require('./config.json').port")/health"
```

## Последние запросы

В таблицу «Последние запросы» попадают успешные генерации из двух источников:

| Тип | Что означает |
|---|---|
| Чат | Генерация из встроенного чата админ-панели |

Для каждой записи отображаются источник, ключ или подпись «Админ-панель», модель, токены, время генерации, HTTP-код и дата.

## Безопасность и резервные копии

- Не открывайте порт Ollama `11434` напрямую в интернет.
- Не публикуйте `config.json`, SQLite-базу, пароли, API-ключи и секреты Telegram.
- Новые API-ключи проверяются по SHA-256-хэшу; зашифрованное значение хранится для повторного просмотра.
- Сохраняйте резервные копии `config.json` и `data/local-ai.db` в защищённом месте.
- Не теряйте `sessionSecret` из конфигурации: от него зависит шифрование сохранённых ключей.
