# Local AI Server

Приватный сервер локальной нейросети на Ubuntu 22.04: Ollama, OpenAI-совместимый API, PM2, Nginx, SSL и панель управления ключами.

## Возможности

- API `POST /v1/chat/completions` и `GET /v1/models`;
- панель администратора на `https://ваш-домен/auth/`;
- документация API на `https://ваш-домен/docs`;
- готовый Base URL `https://ваш-домен/v1` в панели и документации;
- создание, отключение и удаление API-ключей;
- месячные лимиты и учёт токенов, запросов и задержки;
- полный API-ключ хранится только у клиента, в SQLite записывается SHA-256;
- автоматический подбор модели по RAM, CPU и NVIDIA VRAM;
- автоматическая установка Node.js 20, PM2, Ollama, Nginx и Certbot;
- автообновление из ветки `main` каждую минуту с безопасным fast-forward.

## Установка

На сервере заранее создайте A-запись домена, указывающую на IPv4 сервера. Для приватного репозитория клонируйте его через SSH или GitHub CLI, чтобы последующие автообновления имели доступ:

```bash
cd /root
git clone git@github.com:romanich237/local-ii.git
cd local-ii
sudo bash install.sh
```

Установщик попросит домен, email Let's Encrypt, логин и пароль панели длиной 10–15 символов, затем покажет модели, подходящие характеристикам сервера. Проект создаёт отдельный конфиг `local-ii.conf` и не изменяет конфиги других сайтов. По умолчанию используется порт `1488` только на `127.0.0.1`; наружу сервис публикуется через Nginx и HTTPS.

## Использование API

Сначала войдите в `/auth/` и создайте ключ. Полный ключ показывается один раз.

```bash
curl https://ai.example.com/v1/chat/completions \
  -H "Authorization: Bearer lai_ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.5:4b",
    "messages": [{"role": "user", "content": "Привет!"}],
    "stream": false
  }'
```

Если `model` не указан, используется базовая модель из `config.json`.

## Управление

```bash
pm2 status
pm2 logs local-ai-api
pm2 logs local-ai-updater
pm2 restart local-ai-api
curl http://127.0.0.1:1488/health
```

База создаётся автоматически в `data/local-ai.db`. `config.json`, база и логи не попадают в Git.

## Автообновление приватного репозитория

Процесс `local-ai-updater` раз в минуту выполняет `git fetch`, сверяет локальный коммит с `origin/main`, принимает только fast-forward, устанавливает зависимости и перезагружает API. Серверу необходим постоянный доступ к приватному репозиторию — удобнее использовать SSH deploy key с правом чтения.

Отключить обновления можно в `config.json`:

```json
{ "autoUpdate": false }
```

После изменения конфигурации выполните `pm2 restart local-ai-updater`.

## Безопасность

- Ollama и Node.js не слушают публичный интерфейс;
- сессия панели подписана HMAC и хранится в `HttpOnly; SameSite=Strict` cookie;
- пароль хранится как scrypt-хэш;
- после пяти неверных попыток вход блокируется на 15 минут;
- секреты и база исключены из репозитория.

Рекомендуется дополнительно ограничить SSH по ключам, включить UFW (`22`, `80`, `443`) и регулярно создавать резервную копию каталога `data/`.
