Как передавать историю сообщений

API не хранит историю между отдельными запросами. Для продолжения беседы клиент должен передавать в массиве messages предыдущие сообщения пользователя и ответы модели в исходном порядке. Системную инструкцию передавайте с ролью system.

curl {{BASE_URL}}/chat/completions \
  -H "Authorization: Bearer ВАШ_API_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "{{MODEL}}",
    "messages": [
      {"role": "system", "content": "Отвечай на русском и учитывай контекст беседы."},
      {"role": "user", "content": "Меня зовут Алексей."},
      {"role": "assistant", "content": "Приятно познакомиться, Алексей."},
      {"role": "user", "content": "Как меня зовут?"}
    ]
  }'

Встроенный чат админ-панели автоматически отправляет до 40 последних реплик при каждом сообщении. История хранится в браузере до перезагрузки страницы; кнопка «Очистить чат» сбрасывает контекст.

Cursor

Подключение Cursor

  1. Откройте Cursor Settings → Models.
  2. Добавьте API-ключ и включите Use API Key.
  3. Включите Base URL Override.
  4. Укажите {{BASE_URL}}.
  5. Добавьте точный ID модели из GET /v1/models.

Для Agent выбирайте модель с поддержкой tool calling.

OpenAI SDK и ChatGPT

Подключение через OpenAI-совместимый клиент

Local AI Server предоставляет OpenAI-совместимый endpoint. Поэтому его можно использовать из Python-приложений, собственных интерфейсов, LibreChat и других клиентов, в которых разрешено указать собственный Base URL.

from openai import OpenAI

client = OpenAI(
    base_url="{{BASE_URL}}",
    api_key="ВАШ_API_КЛЮЧ"
)

response = client.chat.completions.create(
    model="{{MODEL}}",
    messages=[{"role": "user", "content": "Привет!"}],
    max_tokens=1024
)
print(response.choices[0].message.content)

Важно о ChatGPT: стандартный сайт chatgpt.com и официальное приложение ChatGPT не позволяют просто заменить сервер OpenAI на произвольный локальный Base URL. Для работы с Local AI Server используйте OpenAI SDK или сторонний клиент с настройкой endpoint. Если нужен интерфейс, похожий на ChatGPT, можно развернуть LibreChat или Open WebUI и указать адрес Local AI Server как OpenAI-compatible API.

OpenCode

Подключение OpenCode

Выполните /connect, выберите Other, задайте ID провайдера local-ii и вставьте API-ключ.

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "local-ii": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Local AI Server",
      "options": {"baseURL": "{{BASE_URL}}"},
      "models": {"{{MODEL}}": {"name": "{{MODEL}}"}}
    }
  },
  "model": "local-ii/{{MODEL}}"
}

Диагностика

Типовые ошибки

  • 401: проверьте ключ и его статус в панели.
  • 429: достигнут месячный лимит.
  • 502: проверьте Ollama и наличие модели.
pm2 status
pm2 logs local-ai-api --lines 100
sudo systemctl status ollama
curl http://127.0.0.1:11434/api/tags

Безопасность

Рекомендации

  • Не передавайте ключи в URL или публичные репозитории.
  • Не открывайте порт Ollama 11434 в интернет.
  • Используйте отдельный ключ для каждого клиента.
  • Храните резервные копии конфигурации и SQLite в защищённом месте.
