Cursor

Подключение Cursor

  1. Откройте Cursor Settings → Models.
  2. Добавьте API-ключ и включите Use API Key.
  3. Включите Base URL Override.
  4. Укажите {{BASE_URL}}.
  5. Добавьте точный ID модели из GET /v1/models.

Для Agent выбирайте модель с поддержкой tool calling.

OpenCode

Подключение OpenCode

Выполните /connect, выберите Other, задайте ID провайдера local-ii и вставьте API-ключ.

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "local-ii": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Local AI Server",
      "options": {"baseURL": "{{BASE_URL}}"},
      "models": {"{{MODEL}}": {"name": "{{MODEL}}"}}
    }
  },
  "model": "local-ii/{{MODEL}}"
}

Диагностика

Типовые ошибки

  • 401: проверьте ключ и его статус в панели.
  • 429: достигнут месячный лимит.
  • 502: проверьте Ollama и наличие модели.
pm2 status
pm2 logs local-ai-api --lines 100
sudo systemctl status ollama
curl http://127.0.0.1:11434/api/tags

Безопасность

Рекомендации

  • Не передавайте ключи в URL или публичные репозитории.
  • Не открывайте порт Ollama 11434 в интернет.
  • Используйте отдельный ключ для каждого клиента.
  • Храните резервные копии конфигурации и SQLite в защищённом месте.
